Technical details

Guides and character data

Guides are saved and loaded as JSON. The Character Manager keeps versioned models, guides, curves and skin weights for each character.

Rig building

The framework supports a custom Python rig and an mGear Shifter workflow. The custom rig uses Maya matrix nodes for its control relationships.

Skinning

Skin data and ngSkinTools2 layers can be saved and reapplied during the character workflow.
