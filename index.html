Autorig framework

Python 3 · Maya API 2.0

My personal rigging framework for Maya. Every rig is rebuilt from scratch from data, so the same inputs always give the same rig.

  1. A

    Character Manager

    One place per character: versioned guides, curves, models and skin weights.

  2. B

    Guides

    Locators placed in T‑pose and mirrored, saved to JSON. If a guide exists, that part gets built.

  3. C

    Layered skinning

    Weights authored in ngSkinTools2 layers, stored in a sparse .skc format and reapplied on every build, with topology-independent transfer.

  4. D

    Builder

    Rebuilds the rig from zero: joints, controls, IK/FK and spaces, using matrix nodes only. Custom Python or mGear Shifter engine.
